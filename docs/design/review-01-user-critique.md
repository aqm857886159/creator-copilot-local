## P0(会让用户关掉应用)

| # | 问题 | 处置 |
|---|------|------|

## P1(困惑、试错后能继续)

| # | 问题 | 处置 |
|---|------|------|
| P1-1 | 剪辑页满屏工程师黑话:「本地可审计提案器」「Provider」「沿用同一份合同」「正式文件」「本地提案器」徽标。用户结论:「这软件不是给我做的」。 | S5 文案全部重写为用户语言;工程事实(本地执行、可追溯)转为一句人话或收进详情。 |
| P1-2 | 「粗剪」与「提案」两套词没打通,用户不确定是否同一物。 | 统一用户可见词为「粗剪」;「提案」只留在代码与文档。S5 执行,S2 新增文案先遵守。 |
| P1-3 | 空状态唯一动作「生成 AI 剪辑提案」是右上角小字,页面中央大字均不可点。 | S5:空状态改为页面中央主按钮。 |
| P1-4 | 剪辑页无返回、顶部导航无当前项高亮,用户不知身在何处。 | S5 项目壳解决(← 工作台);过渡期 S2 可先让「工作台」保持高亮。 |
| P1-5 | 首页无完整项目列表感:无封面帧、无时长、无最后修改时间,多项目时靠标题认。 | 事实澄清:工作台已渲染**全部**项目卡(listProjects 全量),缺的是封面帧/时长/时间元信息 → **S2** 卡片元信息。 |
| P1-6 | 导航词「记忆」猜不出含义,用户不敢点。 | **开放问题,需用户拍板**:候选如「创作记忆/风格库/我的偏好」;spec-02 待定项。 |
| P1-7 | 手机素材如何进电脑零指引,「拍好了就扔进来」跳过了最费劲的一步。 | **S3 正门范围**:导入引导需覆盖 AirDrop/数据线/局域网至少一条真实路径。 |
| P1-8 | 五段阶段条无标注,靠猜;黄色含义不明。 | 蓝本 P2 已记录;S2 做卡片时补悬停标注或首次引导。 |
| P1-9 | 生成提案前无预期管理:要多久、是否联网、花不花钱,一字未提。 | S5 文案;涉及付费 Provider 时按「等你定」报价惯例(蓝本已有样式)。 |

## P2(小别扭)

- UUID 徽标应换成项目名(S5);两页视觉气质割裂:黑白工具风 vs 米绿宋体(S5 换肤即消);英文小标 AI EDIT / HUMAN REVIEW / PROPOSAL(S5 去掉);「不会被假素材悄悄替代」自证清白反制造担忧(S5 文案);「剪掉磕巴和重来」的「重来」首读歧义,行话是「废条/重录」(蓝本文案复审);「等你过目」秘书腔(已随本次文案更换消失);「数据在本机」像按钮又不是按钮,且用户真正关心的是「草稿丢不丢」(蓝本 P2);「素材齐了」无依据入口(本次改为「素材已导入」,导入是事实);首页右侧大片留白像半成品(多项目后自然缓解;S2 空/满状态样张对账)。

## 用户人设的正面确认(一句带过)

「拍好了就扔进来」「AI 转写、剪掉磕巴和重来,直接给你一版粗剪」精准命中每周最烦的三件事;整页无运营位干扰,「像给干活的人用的」。方向保持。
